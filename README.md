# PC ARCHITECT

Конфигуратор ПК с каталогом комплектующих, проверкой совместимости, регистрацией и личными сборками.

## Репозитории

| Репозиторий | Папка при совместной работе | Назначение |
| --- | --- | --- |
| `pc-architect-frontend` | `frontend` | Интерфейс приложения |
| `pc-architect-backend` | `backend` | Django, БД и начальные данные |
| `pc-architect-docs` | `documentation` | Проектная документация |

## Скачать одной командой

После заполнения репозиториев на GitHub скачайте файл `get_project.py` из этого репозитория. При установленных Python и Git выполните:

```powershell
python get_project.py --user ВАШ_ЛОГИН --directory D:\misc\PC_ARCHITECT
```

Загрузчик клонирует все три репозитория в соседние папки. Папка назначения должна быть новой или пустой; существующие файлы не перезаписываются. Затем выполните настройку из `backend/README.md`.

Можно клонировать вручную в папки `frontend`, `backend`, `documentation`. При скачивании архивов разместите распакованные папки рядом; другое расположение фронтенда указывается через `FRONTEND_DIR`.

## Использование

1. Откройте `http://127.0.0.1:8000/` после запуска Django.
2. Выберите комплектующие в каталоге или нажмите «Заполнить пример».
3. Зарегистрируйтесь и войдите через кнопку в шапке сайта.
4. Сохраните конфигурацию в личный кабинет.
5. Откройте сохранённую сборку для изменения или удалите с подтверждением.

Личные сборки доступны только владельцу. Несохранённые изменения сбрасываются при перезагрузке.

## Первое размещение на GitHub

Создайте три пустых репозитория с указанными именами, без начальных README и других файлов. Из каждой локальной папки выполните первый коммит и подключите соответствующий удалённый репозиторий. Исходники фронтенда отправляются из `frontend`, бэкенда — из `backend`, документация — из `documentation`. Общую родительскую папку в отдельный репозиторий отправлять не нужно.

Рабочее окружение, пароль БД и локальный ключ подписи в Git не включаются.

Пример для фронтенда, из папки `frontend` (замените `ВАШ_ЛОГИН`):

```powershell
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/ВАШ_ЛОГИН/pc-architect-frontend.git
git push -u origin main
```

Для `backend` и `documentation` выполните те же команды в их папках, указав соответственно `pc-architect-backend` и `pc-architect-docs`. Локальные репозитории уже инициализированы, повторный `git init` не требуется. Если Git запросит имя и email автора, настройте их перед первым коммитом.
